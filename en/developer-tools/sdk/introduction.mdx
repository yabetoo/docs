## Integrate Yabetoo payments easily with our SDKs
Yabetoo makes payment integration straightforward with a full range of SDKs built for different languages. Whether you work in PHP, JavaScript, Python, or Java, there is an SDK for your stack so you can focus on what matters most: building your application.

## Server-side SDKs

Yabetoo's server-side SDKs reduce the work needed to call the Yabetoo REST APIs. Each guide below covers installation and example API requests.

Whether you are building an online store, a service platform, or a SaaS application, our SDKs let you accept payments with minimal effort. Read the guide for your language, install the SDK, and start integrating Yabetoo today.
