---
title: "List webhook endpoints"
description: "List every endpoint of your account."
---

## Endpoint

```bash
GET https://webhook.yabetoopay.com/v1/webhooks/endpoints
```

## Authentication

These are the routes your dashboard uses (**Developers > Webhooks**). They require:

- the `Authorization: Bearer <token>` header, with your Yabetoo user's **session token**;
- the `X-Account-Id` header, the identifier of the merchant account concerned.

<Warning>
  Your secret key (`sk_test_…`, `sk_live_…`) is **not** accepted on these routes. For most integrations,
  create and manage your endpoints from the dashboard.
</Warning>

| Environment | Base URL |
|-------------|----------|
| Production | `https://webhook.yabetoopay.com` |

## Example request

<CodeGroup>
```bash cURL
curl -X GET https://webhook.yabetoopay.com/v1/webhooks/endpoints \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -H "X-Account-Id: YOUR_ACCOUNT_ID"
```
</CodeGroup>

## Response

### 200 OK

Every endpoint of the account, newest first, without pagination.

```json
{
  "data": [
  {
    "id": "we_mi3k8q2xa91f0c4d7e2b",
    "accountId": "acct_xsd",
    "sandboxId": null,
    "url": "https://example.com/webhooks/yabetoo",
    "events": ["intent.succeeded", "intent.failed", "intent.expired"],
    "enabled": true,
    "description": "Production webhook",
    "metadata": { "environment": "production" },
    "createdAt": "2026-11-18T10:12:32.000+00:00",
    "updatedAt": "2026-11-18T10:12:32.000+00:00"
  }
  ]
}
```

## The endpoint object

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Endpoint identifier (`we_…`) |
| `accountId` | `string` | The merchant account |
| `sandboxId` | `string \| null` | Targeted sandbox (`sbx_…`). `null`: the endpoint receives every event of the account |
| `url` | `string` | The URL that receives events |
| `events` | `string[]` | The events received. The `*` wildcard is accepted (`intent.*`) |
| `enabled` | `boolean` | `false`: no more deliveries |
| `description` | `string \| null` | Your description |
| `metadata` | `object \| null` | Your free-form data |
| `createdAt`, `updatedAt` | `string` | ISO 8601 dates |

The signing secret (`whsec_…`) is never part of the object: it is returned separately, on creation, when reading the secret and on rotation.

## Errors

| Status | Body | Cause |
|--------|------|-------|
| `400` | `{ "error": "X-Account-Id header is required" }` | Missing `X-Account-Id` header |
| `401` | `{ "error": "Missing bearer token" }` or `{ "error": "Invalid or expired token" }` | Missing, invalid or expired token |
| `403` | `{ "error": "Account not accessible with this token" }` | The account does not belong to this user |
