## Vue d'ensemble

Le catalogue produits de Yabetoo vous permet de gérer l'ensemble de votre offre commerciale. Que vous vendiez des produits physiques, numériques ou des services, notre système flexible s'adapte à vos besoins.

## Architecture du catalogue

Le **produit** est au centre du catalogue. Le prix lui est directement rattaché :

```
Produit "Formation Pro"
├── Price[]                       prix rattachés au produit
│   ├── Price 25 000 XAF one-time
│   └── Price 5 000 XAF/mois
└── Document[] (images, fichiers)
```

<Steps>
  <Step title="Créer un Produit">
    Définissez les informations de base — nom, description, type (physique, numérique,
    service) — et son prix par défaut dans le même appel avec `defaultPriceData`.
  </Step>
  <Step title="Définir les Prix">
    Rattachez un second prix au produit avec `POST /v1/prices` — un tarif annuel à côté du
    mensuel, ou une seconde devise.
  </Step>
  <Step title="Configurer les Promotions">
    Créez des coupons et codes promo pour offrir des réductions
  </Step>
</Steps>

## Concepts clés

### Types de produits

| Type | Description | Cas d'usage |
|------|-------------|-------------|
| `physical` | Produit physique nécessitant une livraison | Vêtements, électronique, accessoires |
| `digital` | Produit numérique téléchargeable | E-books, logiciels, formations vidéo |
| `service` | Prestation de service | Consultations, abonnements SaaS |

### Types de tarification

<CardGroup cols={2}>
  <Card title="Paiement unique" icon="credit-card">
    Le client paie une seule fois pour accéder au produit. Idéal pour les achats ponctuels.
  </Card>
  <Card title="Abonnement récurrent" icon="repeat">
    Le client est facturé automatiquement à intervalles réguliers. Parfait pour les services continus.
  </Card>
</CardGroup>

### Formats des identifiants

Chaque entité possède un identifiant unique avec un préfixe distinctif :

| Entité | Préfixe | Exemple |
|--------|---------|---------|
| Produit | `prod_` | `prod_abc123def456...` |
| Prix | `price_` | `price_eur_monthly_001...` |
| Coupon | `coupon_` | `coupon_summer_2024...` |
| Code promo | `promo_` | `promo_SUMMER20...` |
