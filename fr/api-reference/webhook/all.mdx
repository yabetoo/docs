## Endpoint

```bash
GET https://webhook.yabetoopay.com/v1/webhooks/endpoints
```

## Authentification

Ces routes sont celles qu'utilise votre tableau de bord (**Développeurs > Webhooks**). Elles demandent :

- l'en-tête `Authorization: Bearer <jeton>`, avec le **jeton de session** de votre utilisateur Yabetoo ;
- l'en-tête `X-Account-Id`, l'identifiant du compte marchand concerné.

<Warning>
  Votre clé secrète (`sk_test_…`, `sk_live_…`) n'est **pas** acceptée sur ces routes. Pour la plupart des
  intégrations, créez et gérez vos endpoints depuis le tableau de bord.
</Warning>

| Environnement | URL de base |
|---------------|-------------|
| Production | `https://webhook.yabetoopay.com` |

## Exemple de requête

<CodeGroup>
```bash cURL
curl -X GET https://webhook.yabetoopay.com/v1/webhooks/endpoints \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -H "X-Account-Id: YOUR_ACCOUNT_ID"
```
</CodeGroup>

## Réponse

### 200 OK

Tous les endpoints du compte, du plus récent au plus ancien, sans pagination.

```json
{
  "data": [
  {
    "id": "we_mi3k8q2xa91f0c4d7e2b",
    "accountId": "acct_xsd",
    "sandboxId": null,
    "url": "https://example.com/webhooks/yabetoo",
    "events": ["intent.succeeded", "intent.failed", "intent.expired"],
    "enabled": true,
    "description": "Webhook de production",
    "metadata": { "environment": "production" },
    "createdAt": "2026-11-18T10:12:32.000+00:00",
    "updatedAt": "2026-11-18T10:12:32.000+00:00"
  }
  ]
}
```

## L'objet endpoint

| Champ | Type | Description |
|-------|------|-------------|
| `id` | `string` | Identifiant de l'endpoint (`we_…`) |
| `accountId` | `string` | Le compte marchand |
| `sandboxId` | `string \| null` | Bac à sable ciblé (`sbx_…`). `null` : l'endpoint reçoit tous les événements du compte |
| `url` | `string` | L'URL qui reçoit les événements |
| `events` | `string[]` | Les événements reçus. Le joker `*` est accepté (`intent.*`) |
| `enabled` | `boolean` | `false` : plus aucune livraison |
| `description` | `string \| null` | Votre description |
| `metadata` | `object \| null` | Vos données libres |
| `createdAt`, `updatedAt` | `string` | Dates ISO 8601 |

Le secret de signature (`whsec_…`) ne fait jamais partie de l'objet : il est renvoyé à part, à la création, à la lecture du secret et à sa rotation.

## Erreurs

| Statut | Corps | Cause |
|--------|-------|-------|
| `400` | `{ "error": "X-Account-Id header is required" }` | En-tête `X-Account-Id` absent |
| `401` | `{ "error": "Missing bearer token" }` ou `{ "error": "Invalid or expired token" }` | Jeton absent, invalide ou expiré |
| `403` | `{ "error": "Account not accessible with this token" }` | Le compte n'appartient pas à cet utilisateur |
