---
title: "Secret de signature"
description: "Lisez ou renouvelez le secret qui signe les webhooks d'un endpoint."
---

## Endpoint

```bash
GET https://webhook.yabetoopay.com/v1/webhooks/endpoints/{id}/secret
```

## Authentification

Ces routes sont celles qu'utilise votre tableau de bord (**Développeurs > Webhooks**). Elles demandent :

- l'en-tête `Authorization: Bearer <jeton>`, avec le **jeton de session** de votre utilisateur Yabetoo ;
- l'en-tête `X-Account-Id`, l'identifiant du compte marchand concerné.

<Warning>
  Votre clé secrète (`sk_test_…`, `sk_live_…`) n'est **pas** acceptée sur ces routes. Pour la plupart des
  intégrations, créez et gérez vos endpoints depuis le tableau de bord.
</Warning>

| Environnement | URL de base |
|---------------|-------------|
| Production | `https://webhook.yabetoopay.com` |

## Paramètres de chemin

| Paramètre | Type | Description |
|---|---|---|
| `id` | `string` | L'identifiant de l'endpoint (`we_…`) |

## Exemple de requête

<CodeGroup>
```bash cURL
curl -X GET https://webhook.yabetoopay.com/v1/webhooks/endpoints/we_mi3k8q2xa91f0c4d7e2b/secret \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -H "X-Account-Id: YOUR_ACCOUNT_ID"
```
</CodeGroup>

## Réponse

### 200 OK

```json
{
  "secret": "whsec_3f9a…"
}
```


## Renouveler le secret

```bash
POST https://webhook.yabetoopay.com/v1/webhooks/endpoints/{id}/rotate-secret
```

Génère un nouveau secret. L'ancien cesse aussitôt de signer : mettez à jour votre serveur juste après.

```bash cURL
curl -X POST https://webhook.yabetoopay.com/v1/webhooks/endpoints/we_mi3k8q2xa91f0c4d7e2b/rotate-secret \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -H "X-Account-Id: YOUR_ACCOUNT_ID"
```

## Erreurs

| Statut | Corps | Cause |
|--------|-------|-------|
| `400` | `{ "error": "X-Account-Id header is required" }` | En-tête `X-Account-Id` absent |
| `401` | `{ "error": "Missing bearer token" }` ou `{ "error": "Invalid or expired token" }` | Jeton absent, invalide ou expiré |
| `403` | `{ "error": "Account not accessible with this token" }` | Le compte n'appartient pas à cet utilisateur |
| `404` | `{ "error": "Webhook endpoint not found" }` | Aucun endpoint avec cet `id` sur ce compte |
