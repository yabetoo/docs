## Obtenir l'URL du lien

Après avoir créé un lien de paiement, vous recevez une URL unique dans la réponse :

```json
{
  "id": "plink_abc123def456ghi789jkl012",
  "url": "https://checkout.yabetoo.com/p/formations",
  "slug": "formations"
}
```

L'URL peut prendre deux formes :
- **Avec slug personnalisé** : `https://checkout.yabetoo.com/p/formations`
- **Avec ID** : `https://checkout.yabetoo.com/p/plink_abc123def456ghi789jkl012`

## Générer un QR Code

Créez un QR code pour permettre aux clients de scanner et accéder au lien :

```bash
curl https://api.yabetoo.com/v1/payment-links/plink_abc123/qr \
  -H "Authorization: Bearer sk_live_..." \
  --output qr-code.png
```

### Paramètres du QR Code

| Paramètre | Type | Description |
|-----------|------|-------------|
| `size` | number | Taille en pixels (défaut: 300) |
| `format` | string | Format d'image : `png`, `svg` (défaut: `png`) |

```bash
curl "https://api.yabetoo.com/v1/payment-links/plink_abc123/qr?size=500&format=svg" \
  -H "Authorization: Bearer sk_live_..." \
  --output qr-code.svg
```

<Tip>
  Les QR codes sont idéaux pour les affiches, flyers, cartes de visite et présentations.
</Tip>

## Paramètres d'URL

Vous pouvez ajouter des paramètres à l'URL pour personnaliser l'expérience :

| Paramètre | Description |
|-----------|-------------|
| `prefill_email` | Pré-remplir l'email du client |
| `prefill_name` | Pré-remplir le nom du client |
| `prefill_phone` | Pré-remplir le téléphone |
| `locale` | Langue de l'interface (`fr`, `en`) |
| `utm_source` | Source de la campagne |
| `utm_medium` | Medium de la campagne |
| `utm_campaign` | Nom de la campagne |

### Exemple avec paramètres

```
https://checkout.yabetoo.com/p/formations?prefill_email=client@example.com&locale=fr&utm_source=newsletter&utm_campaign=summer_2024
```

## Suivi des conversions

### Avec les métadonnées

Ajoutez des informations de suivi lors de la création du lien :

```json
{
  "metadata": {
    "campaign": "summer_2024",
    "source": "newsletter",
    "affiliate_id": "AFF123"
  }
}
```

### Avec les UTM parameters

```
https://checkout.yabetoo.com/p/formations?utm_source=facebook&utm_medium=social&utm_campaign=promo_janvier
```

Ces paramètres sont inclus dans les webhooks pour le suivi des conversions.

## Bonnes pratiques

<AccordionGroup>
  <Accordion title="Sécurité">
    - Ne partagez jamais votre clé secrète
    - Vérifiez que le lien est toujours actif avant de le partager
    - Utilisez HTTPS pour toutes les intégrations
    - Configurez des webhooks pour vérifier les paiements
  </Accordion>

  <Accordion title="Communication">
    - Incluez une description claire du produit ou service
    - Précisez le montant et la devise
    - Indiquez la durée de validité si applicable
    - Ajoutez vos coordonnées de support
  </Accordion>

  <Accordion title="Optimisation">
    - Utilisez des slugs courts et mémorables
    - Testez le lien avant de le partager
    - Adaptez le message au canal de communication
    - Suivez les performances avec les UTM parameters
  </Accordion>

  <Accordion title="Accessibilité">
    - Proposez plusieurs méthodes de paiement
    - Assurez-vous que le lien fonctionne sur mobile
    - Fournissez un support client accessible
  </Accordion>
</AccordionGroup>
