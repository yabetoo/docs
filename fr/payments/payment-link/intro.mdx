## Qu'est-ce qu'un Lien de paiement ?

Un **Lien de paiement** est une URL unique que vous pouvez partager avec vos clients pour collecter des paiements. Contrairement aux Checkout Sessions qui sont créées pour chaque transaction, les liens de paiement sont réutilisables et peuvent être partagés via n'importe quel canal.

<Info>
  **Format de l'identifiant** : `plink_` suivi de 24 caractères alphanumériques.

  Exemple : `plink_abc123def456ghi789jkl012`
</Info>

<CardGroup cols={3}>
  <Card title="product" icon="box">

## Avantages des liens de paiement

<AccordionGroup>
  <Accordion title="Simplicité">
    - Créez des liens en quelques clics via l'API ou le dashboard
    - Aucune compétence technique requise pour les utiliser
    - URL courte et facile à partager
  </Accordion>

  <Accordion title="Flexibilité">
    - Personnalisez le montant, la devise et les produits
    - Définissez des limites d'utilisation
    - Ajoutez des options comme la collecte d'adresse
  </Accordion>

  <Accordion title="Réutilisabilité">
    - Un seul lien pour plusieurs clients
    - Pas besoin de créer une nouvelle session à chaque fois
    - Idéal pour les campagnes marketing
  </Accordion>

  <Accordion title="Traçabilité">
    - Suivez le nombre d'utilisations
    - Recevez des notifications en temps réel
    - Accédez à l'historique des paiements
  </Accordion>
</AccordionGroup>

## Comment ça marche

<Steps>
  <Step title="Création">
    Créez un lien de paiement en spécifiant le type, les produits ou le montant, et les options.
  </Step>
  <Step title="Partage">
    Partagez le lien avec vos clients via email, SMS, WhatsApp, réseaux sociaux ou intégrez-le sur votre site.
  </Step>
  <Step title="Paiement">
    Le client clique sur le lien et accède à une page de paiement sécurisée hébergée par Yabetoo.
  </Step>
  <Step title="Confirmation">
    Une fois le paiement effectué, vous recevez une notification webhook et le client reçoit une confirmation.
  </Step>
</Steps>

## Cas d'utilisation

| Cas d'usage | Type recommandé | Description |
|-------------|-----------------|-------------|
| **Factures** | `amount` | Envoyez des factures avec un lien de paiement intégré |
| **E-commerce** | `product` | Vendez des produits avec variantes (taille, couleur) |
| **Dons** | `amount` (variable) | Permettez aux donateurs de choisir le montant |
| **Abonnements** | `subscription` | Créez des abonnements récurrents |
| **Événements** | `product` | Vendez des billets avec différentes catégories |
| **Services** | `amount` | Facturez des prestations ponctuelles |

## Lien de paiement vs Checkout Session

| Caractéristique | Lien de paiement | Checkout Session |
|-----------------|------------------|------------------|
| **Réutilisabilité** | Réutilisable plusieurs fois | Usage unique |
| **Création** | Une fois, puis partagé | À chaque transaction |
| **Expiration** | Configurable (ou jamais) | Expire après un délai court |
| **Limite d'utilisation** | Configurable (`maxRedemptions`) | Une seule utilisation |
| **URL** | Courte et permanente | Longue et temporaire |
| **Cas d'usage** | Campagnes, partage social | Intégration e-commerce |

## Statuts du lien

| Statut | Description |
|--------|-------------|
| `active` | Lien actif, accepte les paiements |
| `inactive` | Lien désactivé manuellement |
| `expired` | Lien expiré (date `expiresAt` dépassée) |
| `exhausted` | Limite d'utilisation atteinte (`maxRedemptions`) |
